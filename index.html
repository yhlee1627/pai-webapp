강사가 연수 전에 한 번 설정해요. 설정은 이 컴퓨터의 브라우저에만 저장돼요.

VLM 연결 방식

API 키는 강사의 중계 서버에만 두고, 연수생 화면에는 서버 주소와 연수 코드만 들어가요.
API 키를 브라우저에 직접 넣는 방식이에요. 화면을 본 사람은 키를 알아낼 수 있으니 강사 컴퓨터 시연용으로만 쓰고, 연수 뒤에는 키를 폐기하세요.

연수생 배포 링크

이 링크로 웹앱을 열면 중계 서버 주소와 연수 코드가 자동으로 들어가요. 웹앱을 https 주소에 올린 뒤에 쓰세요.

연수생 사용 순서

  1. 서보를 micro:bit P0에 연결하고, 강사가 나눠 준 hex 파일을 micro:bit에 내려받기
  2. Chrome이나 Edge로 이 웹앱 열기
  3. 'micro:bit 연결' → 목록에서 micro:bit 선택 → 서보가 가운데(90°)로 오는지 확인
  4. '카메라 켜기' → 권한 허용, 외장 웹캠이면 목록에서 고르기
  5. 수동 조종 탭에서 버튼으로 움직여 보고, VLM 판단 탭에서 '찍고 묻기'
  6. 결과마다 맞음·틀림 표시 → 기록 탭에서 성공률 확인

micro:bit 코드

같은 코드를 hex 파일로도 제공해요: 심화1_웹앱연결_서보.hex (기본), 심화4_안전장치_완성본.hex (안전 장치). hex를 micro:bit 드라이브에 끌어다 놓으면 되고, MakeCode에 끌어다 놓으면 블록으로 열려요. 웹앱은 L·C·R·N 글자 뒤에 줄바꿈을 붙여 보내요.


        


        
문제 해결

        
    
          
  • micro:bit가 목록에 안 보임: 충전 전용이 아닌 데이터 케이블인지 확인, 케이블을 다시 꽂기
    • 
          
  • 포트를 열 수 없음: MakeCode 탭이 micro:bit에 연결돼 있으면 그 탭을 닫거나 연결을 끊고 다시 시도
    • 
          
  • 서보가 반대로 돌아감: 좌우 반전을 켜거나, micro:bit 코드에서 L·R 각도를 바꾸기
    • 
          
  • 서보가 떨리거나 micro:bit가 다시 켜짐: 3V 직결 대신 서보 확장보드 전원 사용
    • 
          
  • 카메라가 안 켜짐: 주소창 왼쪽 자물쇠 → 카메라 허용, 다른 프로그램이 카메라를 쓰는지 확인
    • 
        

        
VLM 판단 모드에서는 찍은 사진이 VLM 서버로 전송돼요. 얼굴·이름표가 찍히지 않게 물체만 화면에 두세요.
