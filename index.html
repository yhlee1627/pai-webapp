VLM 연결 방식

API 키는 강사의 중계 서버에만 두고, 연수생 화면에는 서버 주소와 연수 코드만 들어가요.
API 키를 브라우저에 직접 넣는 방식이에요. 화면을 본 사람은 키를 알아낼 수 있으니 강사 컴퓨터 시연용으로만 쓰고, 연수 뒤에는 키를 폐기하세요.

연수생 배포 링크

이 링크로 웹앱을 열면 중계 서버 주소와 연수 코드가 자동으로 들어가요. 웹앱을 https 주소에 올린 뒤에 쓰세요.

분류 로봇 준비

  1. 서보를 옆으로 눕혀 고정하고 혼에 접시를 붙이기, 양쪽 아래에 상자 두기. 서보 신호선은 micro:bit P0
  2. 아래 '명령 받기' 코드를 MakeCode에 넣어 micro:bit에 내려받기 (MakeCode 탭은 내려받은 뒤 닫기)
  3. Chrome이나 Edge로 이 웹앱 열기 → 'micro:bit 연결' → 서보가 90°(수평)로 오는지 확인
  4. '카메라 켜기' → 외장 웹캠을 목록에서 고르고 접시 위를 내려다보게 두기
  5. 사람 탭에서 ◀·▶로 물건이 상자로 미끄러지는지, 1.5초 뒤 수평으로 돌아오는지 확인

탭별 두뇌

  • 사람 (1차시): 화면을 보고 버튼으로 분류. 각도 슬라이더는 4차시 '이상 명령' 실험용
  • 규칙 (1차시): 왼쪽·오른쪽 색과 최소 픽셀 수를 정하면 색 픽셀 수로 판단
  • 학습 모델 (2차시): Teachable Machine 공유 링크 → 모델 불러오기 → 클래스마다 보낼 동작 고르기
  • VLM (3·4차시): 분류 기준을 말로 쓰고 '찍고 묻기'. 이유 보이기, 같은 사진 5번 묻기
  • 시연 (5차시): 시연 녹화 → 재생(관측 없이) → 배우기 → 정책 실행(가장 비슷한 시연을 따라 함)
